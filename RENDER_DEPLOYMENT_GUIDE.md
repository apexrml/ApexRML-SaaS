## STEP 1: PREPARE YOUR REPOSITORY

### 1.1 Create GitHub Repository

```bash
# Initialize git repository (if not already done)
git init
git add .
git commit -m "Initial commit: ApexRML SaaS platform"

# Create remote on GitHub and push
git remote add origin https://github.com/yourusername/ApexRML.git
git branch -M main
git push -u origin main
```

### 1.2 Create Render Configuration Files

#### `render.yaml` (Blueprint for auto-deployment)

```yaml
services:
  - type: web
    name: apexrml-api
    env: python
    plan: standard
    buildCommand: pip install -r requirements.txt && flask db upgrade
    startCommand: gunicorn app:app --workers 4 --worker-class sync --bind 0.0.0.0:$PORT
    healthCheckPath: /health
    envVars:
      - key: FLASK_ENV
        value: production
      - key: PYTHON_VERSION
        value: 3.11
    autoDeploy: true
    region: eu-west-1

databases:
  - name: apexrml-postgres
    plan: standard
    ipAllowList: []
```

#### `Procfile`

```
web: gunicorn app:app --workers 4 --worker-class sync --bind 0.0.0.0:$PORT
```

## STEP 3: DATABASE SETUP (SUPABASE)

### 3.1 Create Supabase Project

1. Go to [supabase.com](https://supabase.com)
2. Click "Create a new project"
3. Fill in project details:
   - **Name:** apexrml-production
   - **Database Password:** [Strong random password - save it!]
   - **Region:** London (eu-west-1)
   - **Pricing:** Pro tier (recommended for production)

### 3.2 Get Database Connection String

1. Go to Project Settings → Database
2. Copy "Connection string" (PostgreSQL URI)
3. Format: `postgresql://postgres:[PASSWORD]@[HOST]/postgres`
4. Update `.env`:
```bash
DATABASE_URL=postgresql://postgres:[PASSWORD]@db.[PROJECT_REF].supabase.co:5432/postgres
```

### 3.3 Initialize Database Schema

```bash
# Run schema migration locally first (recommended)
psql $DATABASE_URL < database_schema.sql

# Or run via Flask CLI after deployment
flask init-db
```

### 3.4 Configure Supabase Security

1. Go to Project Settings → Security
2. Enable "JWT Secret validation"
3. Set "JWT secret" to your `JWT_SECRET_KEY`
4. Go to Auth → Policies
5. Create RLS (Row Level Security) policies:

```sql
-- Example: Users can only see their own data
CREATE POLICY "Users can view own data"
ON organizations FOR SELECT
USING (auth.uid() = owner_id);

-- Example: Garage can view own leads
CREATE POLICY "Garages can view own leads"
ON garage_leads FOR SELECT
USING (garage_id IN (
  SELECT id FROM garages WHERE organization_id IN (
    SELECT organization_id FROM organization_members WHERE user_id = auth.uid()
  )
));
```

## STEP 4: CREATE RENDER WEB SERVICE

### 4.1 Connect GitHub Repository

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Web Service"
3. Click "Connect repository"
4. Select your ApexRML GitHub repository
5. Click "Connect"

### 4.2 Configure Web Service

Fill in the following settings:

| Setting | Value |
|---------|-------|
| **Name** | apexrml-api |
| **Environment** | Python 3 |
| **Build Command** | `pip install -r requirements.txt && flask db upgrade` |
| **Start Command** | `gunicorn app:app --workers 4 --worker-class sync --bind 0.0.0.0:$PORT` |
| **Plan** | Standard ($12/month) |
| **Region** | EU (Frankfurt) or EU (London) |
| **Auto-deploy** | Yes |

### 4.3 Advanced Settings

1. **Health Check**
   - Path: `/health`
   - Protocol: HTTP
   - Timeout: 30s

2. **Environment**
   - Python Version: 3.11

3. **Timeouts**
   - Deploy: 15 minutes
   - Idle: 15 minutes (disable for production)

## STEP 9: SSL/TLS CONFIGURATION

### 9.1 Automatic SSL (Render)

Render automatically generates and renews SSL certificates from Let's Encrypt. No action needed.

### 9.2 Force HTTPS

In `app.py`, add:

```python
from flask import Flask

app = Flask(__name__)

# Force HTTPS in production
if not app.debug:
    @app.before_request
    def force_https():
        if request.headers.get('X-Forwarded-Proto', 'http') != 'https':
            url = request.url.replace('http://', 'https://', 1)
            return redirect(url, code=301)
```

### 9.3 Security Headers

Add to `app.py`:

```python
@app.after_request
def set_security_headers(response):
    response.headers['Strict-Transport-Security'] = 'max-age=31536000; includeSubDomains'
    response.headers['X-Content-Type-Options'] = 'nosniff'
    response.headers['X-Frame-Options'] = 'DENY'
    response.headers['X-XSS-Protection'] = '1; mode=block'
    response.headers['Content-Security-Policy'] = "default-src 'self'; script-src 'self' 'unsafe-inline' https://js.stripe.com; style-src 'self' 'unsafe-inline';"
    return response
```

## STEP 10: MONITORING & LOGGING

### 10.1 Enable Sentry (Error Tracking)

1. Go to [sentry.io](https://sentry.io)
2. Create account and new project (Python/Flask)
3. Copy DSN: `https://xxxxx@sentry.io/xxxxx`
4. Add to Render environment: `SENTRY_DSN=<your-dsn>`

### 10.2 Configure Logging

In `app.py`:

```python
import sentry_sdk
from sentry_sdk.integrations.flask import FlaskIntegration

if not app.debug:
    sentry_sdk.init(
        dsn=os.getenv('SENTRY_DSN'),
        integrations=[FlaskIntegration()],
        traces_sample_rate=0.1,
        environment=os.getenv('FLASK_ENV', 'production')
    )
```

### 10.3 View Logs

```bash
# In Render Dashboard
Web Service → Logs (view real-time logs)

# Watch deployment logs
tail -f deployment.log
```

### 10.4 Set Up Alerts

1. In Render Dashboard → Settings
2. Add email notification for deployment failures
3. In Sentry → Alerts → Create alert rule for error spikes

## TROUBLESHOOTING

### Issue: 502 Bad Gateway

**Cause:** Flask app crashed or not responding

**Solution:**
```bash
# Check logs in Render
# Look for error messages in "Logs" tab

# Common issues:
# 1. Missing environment variable
# 2. Database connection failed
# 3. Out of memory

# Fix: Re-deploy with correct env vars
render deploy --manual
```

### Issue: Database Connection Refused

**Cause:** Incorrect DATABASE_URL or network issue

**Solution:**
```bash
# Verify DATABASE_URL format
# Should be: postgresql://user:pass@host:5432/db

# Test connection
psql $DATABASE_URL -c "SELECT 1;"

# If still fails, check:
# 1. Supabase project is active
# 2. Database password is correct
# 3. IP whitelist allows Render servers (should be empty for public)
```

### Issue: Stripe Payments Not Working

**Cause:** Webhook not configured or wrong signing secret

**Solution:**
```bash
# 1. Verify webhook URL in Stripe
# Should be: https://apexrml.co.uk/api/billing/webhook

# 2. Check signing secret
# In Render: STRIPE_WEBHOOK_SECRET env var

# 3. Test webhook
curl -X POST https://apexrml.co.uk/api/billing/webhook \
  -H "Content-Type: application/json" \
  -d '{"type":"ping"}'

# Should return 200
```

### Issue: Emails Not Sending

**Cause:** SendGrid API key invalid or configuration wrong

**Solution:**
```bash
# 1. Verify SENDGRID_API_KEY in Render env
# 2. Check email format (should be MAIL_DEFAULT_SENDER=noreply@apexrml.co.uk)
# 3. Test email

python -c "
from flask_mail import Message
from app import app, mail
with app.app_context():
    msg = Message('Test', recipients=['test@example.com'])
    mail.send(msg)
"
```

### Issue: Service Worker Not Caching

**Cause:** Cache name mismatch or service worker not registered

**Solution:**
```bash
# 1. Open DevTools → Application → Service Workers
# 2. Check if service worker is registered
# 3. Check Cache Storage tab for caches

# 4. Clear and re-register
# In browser console:
navigator.serviceWorker.getRegistrations().then(rs => rs.forEach(r => r.unregister()));
location.reload();
```
